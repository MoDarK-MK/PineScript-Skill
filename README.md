## ✨ Key Capabilities

- 🔍 **63-Rule Linter** — Detects v6 compile errors, repainting traps, scope bugs, and performance limits offline (`PINE001`–`PINE064`). Seven auto-repair with `--fix`.
- ▶️ **Offline Execution** — Run scripts bar-by-bar offline with real series history and parameter sweeps using `pine_run.py`.
- 🛡️ **Production Templates & Risk** — Indicator and strategy scaffolds with theme-aware HUD tables, ATR stops, trailing, partials, and account guards.
- 📦 **Automated Release Pipeline** — One-command bundle generation with stripped comments, input documentation (`INPUTS.md`), and TradingView publish descriptions.
- 🩺 **Single-Command Doctor** — `scripts/doctor.py` validates tests, linting, formatting, budgets, and docs in one pass.

## 🚀 Quick Start

### 1. Scaffold a New Indicator or Strategy
```bash
python3 scripts/scaffold_project.py --kind indicator --name my_indicator --title "My Indicator"
# Or scaffold a strategy with full risk modules:
python3 scripts/scaffold_project.py --kind strategy --name my_strategy --title "My Strategy"
```

### 2. Lint & Auto-Fix
```bash
# Check compliance with all 63 lint rules (PINE001–PINE064)
python3 scripts/pine_lint.py indicators/my_indicator/src/my_indicator.pine

# Apply automatic mechanical fixes
python3 scripts/pine_lint.py indicators/my_indicator/src/my_indicator.pine --fix
```

### 3. Format & Validate
```bash
# Format code style (whitespace, commas, operators)
python3 scripts/pine_fmt.py indicators/my_indicator/src/my_indicator.pine

# Run project health checks
python3 scripts/doctor.py --fast
```

### 4. Version & Generate Release Bundle
```bash
python3 scripts/bump_version.py indicators/my_indicator --bump minor --note "Added volume filter"
python3 scripts/generate_release_bundle.py indicators/my_indicator
```
Outputs in `release/`:
- `<name>.pine` (production script with clean comments stripped)
- `PUBLISH_DESCRIPTION.md` (ready-to-paste description)
- `INPUTS.md` (complete settings inventory)
- `RELEASE_SUMMARY.txt` (pre-flight readiness check)

## 🛠️ CLI Tooling Reference

| Script | Purpose | Typical Command |
|---|---|---|
| `scripts/pine_lint.py` | 63-rule linter catching v6 compile, repaint, and scope bugs | `python3 scripts/pine_lint.py <file> --strict` |
| `scripts/pine_fmt.py` | Pine Script formatter (operator spacing, comma alignment) | `python3 scripts/pine_fmt.py <file>` |
| `scripts/doctor.py` | Runs all checks and yields a single pass/fail verdict | `python3 scripts/doctor.py --fast` |
| `scripts/scaffold_project.py` | Bootstraps indicator or strategy projects with templates | `python3 scripts/scaffold_project.py --kind indicator --name my_ind` |
| `scripts/bump_version.py` | SemVer bumping, changelog updates, and git tagging | `python3 scripts/bump_version.py <dir> --bump minor` |
| `scripts/generate_release_bundle.py` | Builds release `.pine`, `INPUTS.md`, and publish notes | `python3 scripts/generate_release_bundle.py <dir>` |
| `scripts/pine_run.py` | Executes script offline over synthetic or real bars | `python3 scripts/pine_run.py <file> --bars 300` |
| `scripts/inspect_mtf.py` | Analyzes `request.security()` calls for repainting traps | `python3 scripts/inspect_mtf.py <file>` |
| `scripts/check_inputs_compat.py` | Prevents breaking renames that reset user settings | `python3 scripts/check_inputs_compat.py <dir>` |
| `scripts/check_budget.py` | Verifies drawing and request budgets against limits | `python3 scripts/check_budget.py` |
| `scripts/test_webhook.py` | Validates alert JSON payloads and tests mock dispatch | `python3 scripts/test_webhook.py --url <url>` |
| `scripts/convert_v6.py` | Assists in migrating legacy v4/v5 scripts to Pine Script v6 | `python3 scripts/convert_v6.py <file>` |
